This application generates dynamical random tables for encounters in TTRPG games, based on tags.

  • The Search funcion let you explore the collection of items, stored in ./data/items.json.
  • Edit let you modify or add new items through the graphic interface of the application.
  • Finally, Generate will create a series of Dynamic Random Tables for each location.
